E-commerce Customer Behavior Analysis


Описание проекта
Этот проект — комплексный анализ поведения клиентов интернет-магазина на основе реального датасета. 
Цель — выявить ключевые особенности пользователей, сегментировать клиентов и визуализировать данные. 
Проект включает SQL, Python и Power BI.


Используемые инструменты
SQL (MySQL) — построение витрин и агрегация
Python (Jupyter Notebook) — сегментация, визуализация, проверка гипотез
Power BI — дашборд для визуализации ключевых показателей


Этапы проекта

Импорт и очистка данных в MySQL
Создание витрин в SQL:
1. Расходы и удовлетворённость по типу подписки
2. Сумма трат по городам
3. Сегментация клиентов по тратам и активности
4. Сравнение по полу и возрасту
5. Возвратность клиентов (retention)


Анализ в Python
Проверка гипотез
Сравнение по полу и активности
Расчёт медиан, долей, распределений
На основе витрины были построены графики и проверены гипотезы:
- Все VIP-клиенты — мужчины
- Возраст VIP — моложе (медиана 28 лет против 34)
- 100% VIP возвращаются за 15 дней, среди обычных — только 16%
- Поведение VIP-группы стабильно и интенсивно (узкий диапазон возвратов 9–15 дней)


Power BI
Карточки: общее количество клиентов, средний возраст, доля VIP
Диаграммы: расходы, удовлетворенность, возвратность
Графики: возраст по полу, активность по категориям
Выводы.


Ключевые выводы
VIP-клиенты моложе и совершают заказы чаще — большинство возвращаются в течение 15 дней.
Наиболее прибыльная категория — подписка Gold.
Мужчины тратят больше, но в среднем моложе женщин.
Уровень удовлетворенности снижается у клиентов с Bronze подпиской.

Все VIP-клиенты в текущей выборке — мужчины.
Среди обычных клиентов преобладают женщины (57%).
Это может свидетельствовать о разнице в покупательском поведении между полами: мужчины, хотя и составляют меньшую часть клиентов, 
демонстрируют более высокий уровень трат.
Альтернативно, возможен дисбаланс в выборке данных, который стоит учитывать при интерпретации.
